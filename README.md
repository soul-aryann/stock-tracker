# 📈 Spring Boot Stock Tracker API

A REST API built using Spring Boot that allows users to track stock data, view stock history, and manage favorite stocks.

---

## 🚀 Features

- Get stock details by symbol
- View stock overview
- Fetch historical stock data
- Add/remove favorite stocks
- Caching for improved performance
- RESTful API design

---

## 🛠️ Tech Stack

- Java 17+/25
- Spring Boot
- Spring Web
- Spring Cache
- H2 / MySQL (depending on your setup)
- Maven
